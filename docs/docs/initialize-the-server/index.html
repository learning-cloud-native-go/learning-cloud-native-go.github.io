Initialize the Server

Create New Go Module

If you’re new to Go…
  • A Go module is a collection of related Go packages that are versioned together as a single unit.
  • Most often, a version control repository contains exactly one module defined in the repository root. Go also support multi-module workspaces.

Run following commands to create the Go module.

mkdir myapp && cd myapp
go mod init myapp
mkdir -p cmd/app && touch cmd/app/main.go

These steps will generate the following folder structure,

Folder Structure
myapp
├── cmd
│   └── app
│       └── main.go
└── go.mod
Tip

Using the cmd folder is the idiomatic place to store multiple binaries in a Go project.

Add Initial Server

http.ListenAndServe

Important

ListenAndServe listens on the TCP network address addr and then calls Serve with handler to handle requests on incoming connections. Accepted connections are configured to enable TCP keep-alives.

Update cmd/app/main.go.

package main

import (
   "net/http"
)

func main() {
   http.HandleFunc("/livez", livez)
   http.ListenAndServe(":8080", nil)
}

func livez(w http.ResponseWriter, _ *http.Request) {
   w.Write([]byte("."))
}
Tip
  • Run go run cmd/app/main.go from the project root, to start the server. (Ctrl + C to stop the server.)
  • Run curl -i 'http://localhost:8080/livez' and you should see HTTP/1.1 200 OK in its response.

http.NewServeMux

Important

ServeMux is an HTTP request multiplexer. It matches the URL of each incoming request against a list of registered patterns and calls the handler for the pattern that most closely matches the URL.
NewServeMux allocates and returns a new ServeMux. Because, default ServeMux is very limited and not very performant.

Update cmd/app/main.go.

package main

import (
   "net/http"
)

func main() {
   mux := http.NewServeMux()
   mux.HandleFunc("/livez", livez)

   http.ListenAndServe(":8080", mux)
}

func livez(w http.ResponseWriter, _ *http.Request) {
   w.Write([]byte("."))
}
Tip
  • Run go run cmd/app/main.go from the project root, to start the server. (Ctrl + C to stop the server.)
  • Run curl -i 'http://localhost:8080/livez' and you should see HTTP/1.1 200 OK in its response.

http.Server

Important

A Server defines parameters for running an HTTP server. The zero value for Server is a valid configuration.

Update cmd/app/main.go.

package main

import (
   "net/http"
   "time"
)

func main() {
   mux := http.NewServeMux()
   mux.HandleFunc("/livez", livez)

   s := &http.Server{
      Addr:         ":8080",
      Handler:      mux,
      ReadTimeout:  2 * time.Second,
      WriteTimeout: 2 * time.Second,
      IdleTimeout:  5 * time.Second,
   }

   s.ListenAndServe()
}

func livez(w http.ResponseWriter, _ *http.Request) {
   w.Write([]byte("."))
}
Assignment

To verify the timeout, use time.Sleep. After 2 seconds the server will automatically break the connection.

func livez(w http.ResponseWriter, _ *http.Request) {
    time.Sleep(3 * time.Second)
    w.Write([]byte("."))
}

Add Router & Initial Routes

Tip
  • We use Chi as the most idiomatic router with middleware and route groups support.
  • We will add initial routes for /v1/books CRUD.

Add Chi

Run following go get command from the project root.

go get github.com/go-chi/chi/v5

Add Initial Routes

Run following command from the project root.

mkdir -p apps/{router,book} && touch apps/{router/router.go,book/handler.go}

This will generate the following folder structure,

package router

import (
    "net/http"

    "github.com/go-chi/chi/v5"

    "myapp/app/book"
)

func New() *chi.Mux {
    r := chi.NewRouter()
    r.Get("/livez", func(w http.ResponseWriter, _ *http.Request) {
        w.Write([]byte("."))
    })

    r.Route("/v1", func(r chi.Router) {
        r.Route("/books", book.New().Register)
    })

    return r
}
handler.go
app/book/handler.go
package book

import (
    "net/http"

    "github.com/go-chi/chi/v5"
)

type Handler struct{}

func New() *Handler {
    return &Handler{}
}

func (h *Handler) Register(r chi.Router) {
    r.Get("/", h.list)
    r.Post("/", h.create)
    r.Get("/{id}", h.read)
    r.Put("/{id}", h.update)
    r.Delete("/{id}", h.delete)
}

func (h *Handler) list(w http.ResponseWriter, r *http.Request)   {}
func (h *Handler) create(w http.ResponseWriter, r *http.Request) {}
func (h *Handler) read(w http.ResponseWriter, r *http.Request)   {}
func (h *Handler) update(w http.ResponseWriter, r *http.Request) {}
func (h *Handler) delete(w http.ResponseWriter, r *http.Request) {}
Assignment
  • Run go run cmd/app/main.go from the project root, to start the server. (Ctrl + C to stop the server.)
  • Run following curl commands and verify you can see HTTP/1.1 200 OK in the responses.
    • List endpoint: curl -i 'http://localhost:8080/v1/books'
    • Create endpoint: curl -i -X POST 'http://localhost:8080/v1/books'
    • Read endpoint: curl -i 'http://localhost:8080/v1/books/123'
    • Update endpoint: curl -i -X PUT 'http://localhost:8080/v1/books/1'
    • Delete endpoint: curl -i -X DELETE 'http://localhost:8080/v1/books/1'

Add Request Logs Middleware

Tip

We use zerolog with its hlog package, that provides a set of http.Handler helpers to create logs and attach a request ID for each log.

Add Zerolog

Run following go get commands from the project root.

go get github.com/rs/zerolog
go get github.com/rs/xid

Add Handler Logger with Request-ID

Tip
  • Initialize zerolog logger and add log “Starting server” in cmd/app/main.go.
  • Initialize Zerolog’s hlog.NewHandler with Request-ID in app/router/router.go.
  • Attach our request log middleware, that based on Go Cloud Development Kit to the router.

Update cmd/app/main.go and app/router/router.go.

main.go
cmd/app/main.go
package main

import (
    "net/http"
    "os"
    "time"

    "github.com/rs/zerolog"

    "myapp/app/router"
)

func main() {
    l := zerolog.New(os.Stderr).With().Timestamp().Logger()

    mux := router.New(&l)

    s := &http.Server{
        Addr:         ":8080",
        Handler:      mux,
        ReadTimeout:  2 * time.Second,
        WriteTimeout: 2 * time.Second,
        IdleTimeout:  5 * time.Second,
    }

    l.Info().Msgf("Starting server %v", s.Addr)
    s.ListenAndServe()
}
router.go
app/router/router.go
package router

import (
    "net/http"

    "github.com/go-chi/chi/v5"
    "github.com/rs/zerolog"
    "github.com/rs/zerolog/hlog"

    "myapp/app/book"
    mrl "myapp/pkg/middleware/requestlog" // 💡 We add this next
)

func New(l *zerolog.Logger) *chi.Mux {
    r := chi.NewRouter()
    r.Get("/livez", func(w http.ResponseWriter, _ *http.Request) {
        w.Write([]byte("."))
    })

    r.Route("/v1", func(r chi.Router) {
        r.Use(hlog.NewHandler(*l))
        r.Use(hlog.RequestIDHandler("request_id", "X-Request-ID"))
        r.Use(mrl.NewHandler)

        r.Route("/books", book.New().Register)
    })

    return r
}

package requestlog

import (
    "errors"
    "io"
    "net"
    "net/http"
    "time"
)

type logEntry struct {
    ReceivedTime      time.Time
    RequestMethod     string
    RequestURL        string
    RequestHeaderSize int64
    RequestBodySize   int64
    UserAgent         string
    Referer           string
    Proto             string

    RemoteIP string
    ServerIP string

    Status             int
    ResponseHeaderSize int64
    ResponseBodySize   int64
    Latency            time.Duration
}

func ipFromHostPort(hp string) string {
    h, _, err := net.SplitHostPort(hp)
    if err != nil {
        return ""
    }
    if len(h) > 0 && h[0] == '[' {
        return h[1 : len(h)-1]
    }
    return h
}

type readCounterCloser struct {
    r   io.ReadCloser
    n   int64
    err error
}

func (rcc *readCounterCloser) Read(p []byte) (n int, err error) {
    if rcc.err != nil {
        return 0, rcc.err
    }
    n, rcc.err = rcc.r.Read(p)
    rcc.n += int64(n)
    return n, rcc.err
}

func (rcc *readCounterCloser) Close() error {
    rcc.err = errors.New("read from closed reader")
    return rcc.r.Close()
}

type writeCounter int64

func (wc *writeCounter) Write(p []byte) (n int, err error) {
    *wc += writeCounter(len(p))
    return len(p), nil
}

func headerSize(h http.Header) int64 {
    var wc writeCounter
    h.Write(&wc)
    return int64(wc) + 2 // for CRLF
}

type responseStats struct {
    w     http.ResponseWriter
    hsize int64
    wc    writeCounter
    code  int
}

func (r *responseStats) Header() http.Header {
    return r.w.Header()
}

func (r *responseStats) WriteHeader(statusCode int) {
    if r.code != 0 {
        return
    }
    r.hsize = headerSize(r.w.Header())
    r.w.WriteHeader(statusCode)
    r.code = statusCode
}

func (r *responseStats) Write(p []byte) (n int, err error) {
    if r.code == 0 {
        r.WriteHeader(http.StatusOK)
    }
    n, err = r.w.Write(p)
    r.wc.Write(p[:n])
    return
}

func (r *responseStats) size() (hdr, body int64) {
    if r.code == 0 {
        return headerSize(r.w.Header()), 0
    }
    // Use the header size from the time WriteHeader was called.
    // The Header map can be mutated after the call to add HTTP Trailers,
    // which we don't want to count.
    return r.hsize, int64(r.wc)
}

package requestlog

import (
    "io"
    "net"
    "net/http"
    "time"

    "github.com/rs/zerolog/hlog"
)

func NewHandler(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        start := time.Now()

        le := &logEntry{
            ReceivedTime:      start,
            RequestMethod:     r.Method,
            RequestURL:        r.URL.String(),
            RequestHeaderSize: headerSize(r.Header),
            UserAgent:         r.UserAgent(),
            Referer:           r.Referer(),
            Proto:             r.Proto,
            RemoteIP:          ipFromHostPort(r.RemoteAddr),
        }

        if addr, ok := r.Context().Value(http.LocalAddrContextKey).(net.Addr); ok {
            le.ServerIP = ipFromHostPort(addr.String())
        }
        r2 := new(http.Request)
        *r2 = *r
        rcc := &readCounterCloser{r: r.Body}
        r2.Body = rcc
        w2 := &responseStats{w: w}

        next.ServeHTTP(w2, r2)

        le.Latency = time.Since(start)
        if rcc.err == nil && rcc.r != nil {
            // If the handler hasn't encountered an error in the Body (like EOF),
            // then consume the rest of the Body to provide an accurate rcc.n.
            io.Copy(io.Discard, rcc)
        }
        le.RequestBodySize = rcc.n
        le.Status = w2.code
        if le.Status == 0 {
            le.Status = http.StatusOK
        }
        le.ResponseHeaderSize, le.ResponseBodySize = w2.size()
        hlog.FromRequest(r).Info().
            Time("received_time", le.ReceivedTime).
            Str("method", le.RequestMethod).
            Str("url", le.RequestURL).
            Int64("header_size", le.RequestHeaderSize).
            Int64("body_size", le.RequestBodySize).
            Str("agent", le.UserAgent).
            Str("referer", le.Referer).
            Str("proto", le.Proto).
            Str("remote_ip", le.RemoteIP).
            Str("server_ip", le.ServerIP).
            Int("status", le.Status).
            Int64("resp_header_size", le.ResponseHeaderSize).
            Int64("resp_body_size", le.ResponseBodySize).
            Dur("latency", le.Latency).
            Msg("")
    })
}
